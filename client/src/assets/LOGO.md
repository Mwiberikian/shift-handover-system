# Logo source

https://commons.wikimedia.org/wiki/File:Kenya_Airways_logo.svg
(downloaded from https://upload.wikimedia.org/wikipedia/commons/0/0d/Kenya_Airways_logo.svg).

**trademarked**: copyright does not restrict its use, but trademark law still
applies, so it identifies the airline and should not be modified.
